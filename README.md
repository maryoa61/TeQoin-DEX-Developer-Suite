# 🚀 MultiSwapper - Automated EVM & Testnet Swap Bot

اسکریپت و ابزار هوشمند برای انجام خودکار سواپ‌های دوره‌ای در شبکه‌های سازگار با EVM (مانند Robinhood Testnet, TeQoin, Sepolia, Arbitrum و ...) با استفاده از **Foundry** و **GitHub Actions**.

---

## ❓ چرا سکرت‌ها (Secrets) را در مخزن پیدا نکردید؟

> **نکته بسیار مهم امنیتی:**
> سکرت‌های گیت‌هاب (**GitHub Secrets**) به دلایل امنیتی **هرگز در میان کدهای پروژه یا فایل‌ها وجود ندارند** و توسط گیت‌هاب در مخزن ذخیره نمی‌شوند!  
> شما باید خودتان این متغیرهای محرمانه (مانند کلید خصوصی و آدرس‌های توکن) را در پنل تنظیمات مخزن گیت‌هاب خود تعریف کنید.

### 📍 نحوه ایجاد سکرت‌ها در گیت‌هاب (مرحله‌به‌مرحله):

1. وارد مخزن گیت‌هاب خود شوید (مثلاً `github.com/maryoa61/MultiSwapper`).
2. در نوار بالای مخزن، روی تب **Settings** (تنظیمات) کلیک کنید.
3. در منوی سمت چپ، بخش **Security** را پیدا کرده و روی **Secrets and variables** کلیک کنید.
4. زیرمجموعه **Actions** را انتخاب کنید.
5. روی دکمه سبز رنگ **New repository secret** کلیک کنید.
6. سکرت‌های زیر را یکی‌یکی با نام (Name) دقیق و مقدار (Secret) مربوطه اضافه کنید:

---

## 🔑 لیست سکرت‌های مورد نیاز (Repository Secrets)

| نام سکرت (Secret Name) | الزامی؟ | توضیحات |
| :--- | :---: | :--- |
| `RPC_URL` | **بله** | آدرس RPC شبکه تستی یا اصلی (مثال: آدرس نود شبکه Robinhood Testnet) |
| `TOKEN_A` | **بله** | آدرس کانترکت توکن مبدا (توکنی که می‌خواهید بفروشید/سواپ کنید) |
| `TOKEN_B` | **بله** | آدرس کانترکت توکن مقصد (توکنی که می‌خواهید دریافت کنید) |
| `KEY_1` | **بله** | کلید خصوصی (Private Key) ولت اول شما به صورت هگزادسیمال |
| `KEY_2` | خیر | کلید خصوصی ولت دوم (در صورت نیاز به سواپ همزمان چند ولت) |
| `KEY_3` | خیر | کلید خصوصی ولت سوم (اختیاری) |
| `ROUTER_ADDRESS` | خیر | آدرس روتر یونی‌سواپ (در صورت خالی بودن، به صورت پیش‌فرض از آدرس استاندارد کد استفاده می‌شود) |

## ⚙️ نحوه عملکرد ربات سواپ خودکار

1. **اجرای خودکار (Scheduled):**
   - به طور خودکار هر ۳ ساعت یک‌بار توسط GitHub Actions اجرا می‌شود (`cron: '0 */3 * * *'`).
   - شامل یک تاخیر تصادفی (Random Sleep) بین ۱ تا ۶۰ دقیقه برای طبیعی به نظر رسیدن زمان تراکنش‌ها.

2. **اجرای دستی (Manual):**
   - برای تست سریع، وارد تب **Actions** در گیت‌هاب شوید.
   - از ستون چپ روی **Robinhood Testnet Auto-Swap Bot** کلیک کنید.
   - روی دکمه **Run workflow** کلیک نمایید تا فرآیند فوراً آغاز شود.

## 🛠️ مشخصات فنی

- **ابزار کامپایل و اجرا:** Foundry (Forge)
- **کانترکت اسکریپت:** `script/AutoSwapper.s.sol`
- **ورک‌فلو اکشن:** `.github/workflows/auto-swap.yml`
- **نسخه سالیدیتی:** `^0.8.20`
- **ددلاین تراکنش‌ها:** تنظیم شده روی `block.timestamp + 1200` (۲۰ دقیقه) برای جلوگیری از خطای Revert ناشی از ددلاین صفر.
